# 把話說進心裡

親職善意溝通的 62 頁互動式網頁簡報。

內容包含 4D／4C 複習、我訊息與你訊息比較，以及讚美、感謝、失落支持與期許、增能、道歉、回應負面語言。

## 操作

- 左右方向鍵或頁面箭頭：換頁。
- 空白鍵或「揭示參考」：顯示本頁參考答案，不自動換頁。
- 「收起答案」：再次隱藏答案。
- 章節選單：跳至單元。
- 講師筆記：查看教學提醒、公版頁碼與改寫說明。
- 重新載入：答案恢復隱藏。

## 檔案

- `index.html`：簡報入口。
- `content.js`：課程文案、情境、參考回應與講師筆記。
- `app.js`：播放、揭示與導覽。
- `style.css`：投影與手機版面。
- `sources.html`：來源及教學改寫說明。

純靜態網頁，無帳號、資料收集、分析追蹤或外部字型依賴。來源資料列於來源頁；公版原始檔不包含在本儲存庫中。
